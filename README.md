# portfolio-ravi

To use your personal profile image in the hero section:

1. Place your image file at `public/profile.png`.
2. Restart or refresh the Vite dev server at `http://localhost:5173/`.

Notes:

- The hero component uses `src="/profile.png"`.
- If `profile.png` is missing, the app falls back to a generated avatar.
- For best results, use a square image around `512x512` pixels.
